# Published ERN 2016 Fixture

Frozen inputs for the published-ERN historical replication target.

- Historical window: February 1871 through September 2016.
- Projection starts October 2016 with the published ERN assumptions
  (equity 6.6% real p.a.; bonds 0% for 120 months, then 2.6% real p.a.).
- Cohorts: February 1871 through December 2015 (1,739 cohorts).

These files preserve the rounded canonical values used to generate
`data/ern/p49_oracle_table.csv`. They are a historical reference fixture, not
production data. Production uses the workbook-derived files in `data/ern/`.
